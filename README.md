# Домашние задания по Python

## ДЗ №1

Заполните функции в `homework1/factorial.py` и `homework1/median.py`, сохранив имена функций и файлов. Условия заданий доступны на сайте курса. Функции должны возвращать результат с помощью `return`.

Локальная проверка из корня репозитория:

```bash
python -m unittest discover -s tests -v
```

На macOS или Linux вместо `python` может потребоваться `python3`, в Windows — `py`.

После отправки изменений в ветку и создания pull request проверка запускается автоматически; результат отображается в разделе Checks pull request. Для первого запуска из fork может потребоваться разрешение преподавателя. Проверки для fork на вкладке Actions могут требовать отдельного включения. Изменения отправляйте в собственную ветку; не изменяйте файлы тестов и workflow. Тесты открыты и предназначены для учебной проверки.
